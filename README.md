# Кими Ассистент (KimiAssistent)

Android-приложение-ассистент в духе Gemini, но работающее на **Kimi API (Moonshot AI)**.

## Возможности

- 💬 **Чат с Кими** — текстовый чат с историей (на движке Moonshot/Kimi, OpenAI-совместимый API).
- ◎ **Плавающий кружок** поверх любого приложения (как у Gemini): тап → меню быстрых действий. Работает, когда включишь его кнопкой «◎» в шапке чата и выдашь разрешение «поверх других окон».
- 📋 **Скопировать текст с экрана** — выделяешь пальцем область на любом экране → Kimi распознаёт текст (vision-модель) → текст автоматически кладётся в буфер обмена.
- 🖼 **Спросить про область экрана** — выделяешь область → она скриншотится и отправляется Кими картинкой с вопросом.
- 📸 **Скриншот целиком в чат** — кнопка камеры в меню снизу: экран прикрепляется к сообщению.
- 🎤 **Голосовой ввод** — кнопка микрофона в меню снизу (распознавание речи Android, русский язык).
- 📋 Долгое нажатие на сообщение — копировать текст. Настройки API — по кнопке «⚙».

## Настройка (после установки)

1. Открой приложение → нажми **⚙**.
2. Вставь **API-ключ Kimi** — получить на [platform.moonshot.ai](https://platform.moonshot.ai) (для Китая — platform.moonshot.cn и адрес `https://api.moonshot.cn/v1`).
3. Модель по умолчанию: `moonshot-v1-8k-vision-preview` (поддерживает картинки). Можно указать любую доступную модель Moonshot/Kimi.
4. Для плавающего кружка выдай приложению разрешение «Поверх других окон» (приложение само откроет нужную настройку).
5. Для скриншотов Android попросит разрешить запись экрана — согласись (один раз на сессию).

## Сборка

CI (GitHub Actions, workflow `build.yml`) при каждом пуше собирает debug-APK и кладёт его в `apk/KimiAssistent-debug.apk` в ветке.

Локально:

```bash
gradle assembleDebug
# → app/build/outputs/apk/debug/app-debug.apk
```

## Технологии

Kotlin, Android SDK 34 (minSdk 26 / Android 8+), RecyclerView, OkHttp, MediaProjection API (скриншоты), SYSTEM_ALERT_WINDOW (оверлей), SpeechRecognizer (голос), org.json.
