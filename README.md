# Кими Ассистент (KimiAssistent)

Android-приложение-ассистент в духе Google Gemini, но работающее на **Kimi API (Moonshot AI)** — или на любом другом OpenAI-совместимом API, включая **бесплатный Gemini** от Google AI Studio.

## Возможности

- 🚀 **Запуск как Google Ассистент** — назначь приложение цифровым помощником системы, и жест (долгое нажатие «Домой» / свайп из нижнего угла / удержание кнопки питания) открывает панель Кими **поверх любого приложения** с авто-включением микрофона.
- 💬 **Чат с Кими** — текстовый чат с историей (OpenAI-совместимый API).
- ◎ **Плавающий кружок** (опционально) — альтернативный способ вызова поверх приложений.
- 📋 **Скопировать текст с экрана** — выделяешь пальцем область на любом экране → ИИ распознаёт текст → текст автоматически кладётся в буфер обмена.
- 🖼 **Спросить про область экрана** — выделяешь область → она скриншотится и отправляется ИИ картинкой с вопросом.
- 📸 **Скриншот целиком в чат** — кнопка камеры в меню снизу: экран прикрепляется к сообщению.
- 🎤 **Голосовой ввод** — кнопка микрофона + авто-прослушивание при жесте ассистента (распознавание речи Android, русский язык).
- 📋 Долгое нажатие на сообщение — копировать текст. Настройки API — по кнопке «⚙».

## Как включить запуск «как Google Ассистент»

1. Открой приложение → **⚙** → «🛠 Назначить помощником по умолчанию» (или Настройки Android → Приложения → Приложения по умолчанию → Цифровой помощник → **Кими Ассистент**).
2. Теперь долгое нажатие кнопки «Домой» (или свайп из угла при жестовой навигации, или удержание кнопки питания на Android 12+) открывает панель Кими над текущим экраном.
3. Кружок (◎) остаётся как дополнительный вариант вызова.

## Бесплатные варианты ИИ (⚙ → пресеты)

| Провайдер | Ключ | Особенности |
|---|---|---|
| **Google AI Studio (Gemini)** — 🆓 | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) | Полностью бесплатно, без карты и срока (Flash-модели, ~10 запросов/мин). Понимает картинки. |
| **OpenRouter** — 🆓 | [openrouter.ai](https://openrouter.ai) | Модели с суффиксом `:free`, лимиты по запросам. |
| **Kimi (Moonshot)** | [platform.moonshot.ai](https://platform.moonshot.ai) | Новым аккаунтам — стартовые кредиты; далее недорогая оплата. Для Китая — platform.moonshot.cn и адрес `https://api.moonshot.cn/v1`. |

В настройках нажми нужный пресет (адрес и модель подставятся сами), вставь ключ — готово.

## Сборка

CI (GitHub Actions, workflow `build.yml`) при каждом пуше собирает debug-APK и кладёт его в `apk/KimiAssistent-debug.apk` в ветке.

Локально:

```bash
gradle assembleDebug
# → app/build/outputs/apk/debug/app-debug.apk
```

## Технологии

Kotlin, Android SDK 34 (minSdk 26 / Android 8+), RecyclerView, OkHttp, VoiceInteractionService/VoiceInteractionSession (системный жест ассистента), MediaProjection API (скриншоты), SYSTEM_ALERT_WINDOW (оверлей), SpeechRecognizer (голос), org.json.
